## 完整结果缓存与低并发后台刷新

用户要求缓存名称搜索结果，保持同步 500 毫秒，超时后执行最多 30 秒的异步搜索；每次缓存命中返回旧结果并在后台核验，变化时更新供下次查询使用。实现为 Manager 生命周期内共享的内存缓存；按搜索根逻辑别名及真实地址、有效深度、大小写归一关键词和授权根身份隔离，缓存完整排序集合，分页仅复制当前页。查询前重新核验根身份和范围，选取与最终执行仍实时 Validate，缓存不能授予目录权限。
