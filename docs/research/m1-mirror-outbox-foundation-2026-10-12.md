# M1 镜像与投递基础切片

日期：2026-10-12。仅本地实现与故障测试；没有切换真实 M0 listener，没有新增群或消息。本切片不代表 M1 或一期发布完成。

## 已实现

- schema v3 保留 M0 与 v2 发现 / 群创建状态，增加 mirrors、outbound、不可变 outbound_attempts 和 history_watermarks。
- 公开卡片与待投递记录先持久化，完整扫描水位同事务保存；建群尚未完成时可以等待绑定。旧快照拒绝覆盖新快照，完成卡不被迟到执行中状态覆盖，相同内容不安排 PATCH。
- 一条线程只领取一个远程写请求。领取时冻结 UUID、正文、目标和真实父消息；human 使用 send，progress / final 使用 reply，已确认的原卡使用 PATCH。父消息尚未确认时等待，不退化为普通发送。
- 新进度合并到镜像的最新版本，发送中的 attempt 保留原正文；返回旧版本确认后，再 PATCH 最新版本。非终态过程更新最短间隔两秒，终态更新可立即领取。
- 崩溃恢复把 dispatching 变为 unknown。未知和明确拒绝均不自行再次调用网关；获得原消息 ID 后可以确认同一次投递，并继续更新原卡。未知过程卡不阻止具有已知原始父消息的独立最终结果。
- 长回复以完整序列化卡片字节数拆分，默认保守上限 20,000 字节，包括转义、来源与分片序号。Raw 拼回原始正文；显示用 Body 为长代码补齐围栏。中文、emoji、控制字符、长行、段落、反引号及波浪线围栏均覆盖测试。

## 验证

本地测试覆盖：建群前入库与重启；父消息依赖；快照事务回滚与水位不推进；同轮并发领取唯一；进度合并、节流与终态保护；重复远程确认不回退版本；旧 v2 数据迁移保留原生未知操作；网关调用前已落账；飞书接受后本地 DB 保存失败，重启不再发送；reply 拒绝无 send fallback；返回空 message ID 保持未知。

分片测试覆盖精确 JSON 大小边界、UTF-8、正文无丢失、稳定分片序号、代码语言 / 围栏保留及无法装入的原子围栏返回明确错误。标准 Markdown 围栏支持最多三空格缩进；列表 / 引用内嵌围栏暂不解析，超长原子语言说明返回错误，不截断正文。

完成时执行 `go test -race ./...`、`go vet ./...` 和 `git diff --check`；这些验证只证明当前代码与本地模拟的行为。

## 尚未完成

正式快照协调器需要从完整分页原生历史生成公开卡片、关联飞书输入以避免正文重复、保持原 turn 的首条输入锚点，并在群创建期间持续保存内容。正式服务还需要统一事件路由、输入 / 动作恢复和通知策略。

当前 outbox 不实现未知请求的远程自动核验或幂等有效期内的精确重试，不自动重试明确限流；正式发布前必须补齐这些路径。@ 应在实际送达时重新判断，不能把带有过期接收者的正文提前存为未来投递。真实 UI / App 自动发现、多轮恢复和发布矩阵均仍待集成验收。

用户已完成 M0 所需实际操作，今晚没有新增需用户协助的步骤。fork 按用户要求延期，发现模块已有 `fork_deferred` 和代码 TODO；普通会话与注册 Git 工作树仍在一期范围内。
